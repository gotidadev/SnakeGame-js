# 🐍 Snake Game

Um Snake Game desenvolvido do zero com **HTML, CSS e JavaScript** usando a **Canvas API**.

[Clique aqui para jogar ](https://gotidadev.github.io/SnakeGame-js/)

## 🎮 Controles

* `W` / `↑` — Cima
* `A` / `←` — Esquerda
* `S` / `↓` — Baixo
* `D` / `→` — Direita

## 🧩 Sobre

* Grid de **20 × 20**
* **400 blocos** disponíveis
* Canvas de **500 × 500px**
* Sistema de pontuação
* Recorde salvo no `localStorage`
* Crescimento da cobra
* Detecção de colisão
* Geração aleatória de comida

## 🛠️ Tecnologias

* HTML
* CSS
* JavaScript
* Canvas API
* LocalStorage
